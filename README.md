# Simple TODO List Application

A beautiful, responsive TODO list application built with HTML, CSS, and JavaScript.

## Features

- ✅ Add new tasks
- ✏️ Edit existing tasks
- ❌ Delete tasks
- 🔄 Mark tasks as complete/incomplete
- 🔍 Filter tasks (All, Active, Completed)
- 📊 Task statistics
- 🗑️ Clear all completed tasks
- 💾 Local storage persistence
- 📱 Responsive design
- 🎨 Modern UI with animations
- 🔔 Toast notifications

## How to Use

1. **Open the application**: Open `index.html` in your web browser
2. **Add a task**: Type your task in the input field and press Enter or click "Add"
3. **Mark as complete**: Click the circle checkbox next to any task
4. **Edit a task**: Click the yellow edit button and modify the text
5. **Delete a task**: Click the red delete button
6. **Filter tasks**: Use the "All", "Active", or "Completed" buttons
7. **Clear completed**: Click "Clear Completed" to remove all finished tasks

## Files Structure

- `index.html` - Main HTML structure
- `styles.css` - CSS styling and animations
- `script.js` - JavaScript functionality
- `README.md` - This documentation file

## Browser Compatibility

Works in all modern browsers including:
- Chrome
- Firefox
- Safari
- Edge

## Local Storage

Your tasks are automatically saved to your browser's local storage, so they'll persist between sessions.

## Getting Started

Simply double-click on `index.html` or open it in your preferred web browser to start using the TODO list!
